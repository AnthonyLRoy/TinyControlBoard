## Cross-component mismatch summary (Rule 3a)

1. **Front-panel connector pin 17 vs. firmware button index 7** (see table above) — hardware wiring
   diagram and firmware button registry disagree about which command the physical "Prev Menu Item"
   connector pin actually triggers.
2. **No other cross-component protocol mismatches were found.** The UART wire format
   (`lib/protocol/uartProtocol.hpp`/`.cpp`), the Python framing (`scripts/rpi/home/antho/protocol.py`),
   and the BLE payload parsing (`android/.../ble/BleProtocol.kt`) all agree on: header layout, checksum
   algorithm, `CommandId` values, and `MessageType` values, as of commit `402f526`.
